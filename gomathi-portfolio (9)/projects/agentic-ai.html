Agentic AI & Frameworks

A one-credit course exploring agentic AI concepts — learning how to use AI tools and frameworks to build and manage autonomous agent workflows.

🧠 AI Agents 🛠️ AI Frameworks & Tools
View on GitHub

01 Overview

This course introduced the core ideas behind agentic AI — systems where an AI doesn't just answer a single prompt, but plans, uses tools, and carries out multi-step tasks autonomously. The focus was on understanding how these agent frameworks are structured and how to apply them practically.

02 Key Concepts Covered

  • What makes an AI system "agentic" — planning, tool use, and iterative task execution
  • Working with AI tools and frameworks to manage agent workflows end-to-end
  • Practical exposure to how autonomous agents are configured and directed toward a goal
