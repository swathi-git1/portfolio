Spotify Trends Dashboard

A Snowflake-based analytics project modeling Spotify track performance — built as part of a one-credit Data Analytics using Snowflake course, paired with the SnowPro Associate: Platform certification.

❄️ Snowflake 🗒️ SQL
View on GitHub View Certificate

01 Overview

This project models Spotify track-level data inside a Snowflake data warehouse, then queries it to surface trends — which tracks are gaining streams fastest, how long songs stay popular, and which genres or countries are driving growth.

02 Data Model

The core table, SPOTIFY_TRENDS, captures the following fields:

CREATE OR REPLACE TABLE SPOTIFY_TRENDS ( TRACK_NAME STRING, ARTIST_NAME STRING, STREAMS INT, STREAM_CHANGE INT, "DAY" INT, GENRE STRING, COUNTRY STRING, POS INT, DAYS INT, VIRAL_SCORE INT, TREND STRING, POPULARITY_CATEGORY STRING, LONGEVITY STRING );

03 What It Analyzes

📈 Streaming Trends

Tracking STREAMS and STREAM_CHANGE over time to identify which tracks are rising, plateauing, or declining day over day.

🔥 Viral Scoring

A computed VIRAL_SCORE and TREND label classify how quickly a track is gaining traction relative to its position and stream velocity.

🌍 Genre & Geography

Breaking down performance by GENRE and COUNTRY to compare regional listening patterns and genre-level popularity.

⏳ Longevity

A LONGEVITY and POPULARITY_CATEGORY classification distinguishes one-hit spikes from tracks with sustained, long-term listenership.
