Crime Management System

A Java-based system to record, track, and manage crime reports, case statuses, and officer assignments with a structured database backend.

💻 Java 🗄️ Database-driven
View on GitHub Alt Version

01 Overview

The Crime Management System digitizes the process of logging and tracking criminal cases — replacing manual paper records with a structured, queryable system. It models the real-world entities involved in case handling: crime reports, case statuses, and officer assignments, each represented as classes with clear responsibilities.

02 Core Features

  • Record new crime reports with structured fields (date, location, type, description)
  • Track case status through its lifecycle (Open, Under Investigation, Closed)
  • Assign and reassign officers to active cases
  • Persist records in a database for reliable retrieval and reporting

03 Why OOP Fits This Problem

🔒 Encapsulation

Each case, officer, and report is encapsulated as an object — keeping sensitive fields like case status changes controlled through defined methods rather than open access.

🗄️ Database Integration

Java's structured classes map cleanly onto database tables, making it straightforward to persist and query crime records reliably across sessions.

🌳 Extensibility

New case types or officer roles can be added by extending existing classes, without restructuring the whole system — a direct benefit of an object-oriented design.
